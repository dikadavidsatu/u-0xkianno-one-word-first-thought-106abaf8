A single-word entry for the [One Word, First Thought bounty](https://make.fun/bounty/u-0xkianno-one-word-first-thought-106abaf8). The program writes exactly one word — petrichor, the earthy scent that rises when rain first strikes dry ground — to `entry.txt`. It is vivid and specific, surprising rather than safe, and its soft, rolling sound rewards a second look. The program validates the word against the gate (1 to 24 characters, not only white space, exactly one word) before writing, uses only Node builtins, and is fully deterministic.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output /usr/bin/node main.ts
```
