A single-word entry for the [One Word, First Thought bounty](https://make.fun/bounty/u-0xkianno-one-word-first-thought-106abaf8). The program writes exactly one word — vellichor, the strange wistfulness of used bookshops, shelves of second-hand books that passed through lives you will never know — to `entry.txt`. It is surprising rather than safe, vivid and specific in nine letters, and its soft, rolling sound rewards a second look. The program validates the word against the gate (UTF-8 text of 1 to 24 characters, not only white space, exactly one word) before writing, uses only Node builtins, and is fully deterministic.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output /usr/bin/node main.ts
```
